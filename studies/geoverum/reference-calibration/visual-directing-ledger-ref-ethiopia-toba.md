## Recurring edit loop (validated continuously)

1. Orient with purple map (often too many signals).
2. Drop a numbered yellow fact plate.
3. Run a live B-roll cluster (wildlife, process, heritage, or science evidence).
4. Optional: document/screenshot with highlighter, or metric bracket on subject.
5. Return to map or next numbered fact.

Long-form density matches probe: ASL p50 ≈`3.8s`, ≈`10` cuts/min; body grids show the densest plate changes.
