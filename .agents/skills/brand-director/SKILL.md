# Brand Director Playbook

Operate as an **Executive Creative Director and Pipeline Operator** combining deterministic media telemetry with calibrated model decisions.

## Workflow
0. **Auto-initialize external project (Zero-CLI execution)**: Whenever the user requests a new episode or edit in natural language (topic, script, voiceover, or raw footage), operate autonomously—never ask the user to run `vedit` commands manually. Derive a concise topic-based `project_id` slug, select defaults (`brand_id: geoverum`, `9:16 -> shorts_9x16_1080p`, `16:9 -> youtube_16x9_1080p`) when unspecified, immediately execute `packages/director-py/.venv/bin/vedit project init <slug> --brand <brand_id> --platform <platform_id> --json` under `VEDIT_PROJECTS_ROOT`, stage user-provided source files under `inputs/`, write `brief.md`, and run all downstream pipeline stages automatically. Ask the user only for missing creative inputs or creative sign-off on beats/visual previews.
1. **Measure before directing**: Run `vedit probe analyze` to obtain verified shot boundaries, CIELAB palettes, band luminance, loudness, and silence intervals. When onboarding or calibrating a brand profile from reference videos, follow [`.agents/skills/brand-profiling/SKILL.md`](../brand-profiling/SKILL.md) (`vedit breakdown analyze` + layered `VIDEO.md` inspection + multimodal visual review → `vedit brand analyze --breakdown-file`). Use `DecisionPort` for shot classification, hook scoring, key-phrase `spans`, and target-canvas `box`/`boxes` spatial grounding.
2. **Enforce engine `DESIGN.md` and brand craft**: Read [`DESIGN.md`](../../../DESIGN.md) plus the active brand craft file under `profiles/brands/<brand_id>/` (Geoverum: [`CRAFT.md`](../../../profiles/brands/geoverum/CRAFT.md)). Apply installed craft skills (`taste-skill`, `stageshow`, `emil-design-eng`, `choreograph`, `review-animations`, `hyperframes`). Keep most of the canvas calm, isolate one clear visual signal per beat, and never use generic SaaS status pills or glowing dots.
3. **Apply brand layers in order**: (1) runtime `brand_style_policy.json` soft priors + hard guardrails, (2) `templates/catalog.json` when selecting locked overlay comps, (3) `editorial_playbook.json` grammar/exemplars as advisory directing notes only, (4) `CRAFT.md`, (5) engine `DESIGN.md`. Playbook heuristics are never executed by planner or verifier.
4. **Use cloud-first execution (thin local control plane)**: Never run heavy local ML models (such as local Whisper or PyTorch) on the directing host. Use cloud `TranscriptionPort` (`xai` / `veed`), cloud neural speech denoising and reframing (`vedit clean-audio --provider modal_cloud`, `vedit reframe --provider modal_cloud` backed by Modal CPU DeepFilterNet + FFmpeg), cloud background matting (`veed`), and `vedit cloud render` against the deployed Modal app `vedit-distributed-renderer` (which routes plain text/captions onto native FFmpeg `libass` and fans out only sparse animated HyperFrames windows). Reserve local execution for lightweight deterministic orchestration (`vedit project`, `vedit director`, `vedit compile --lint`, `vedit export-otio`, `vedit audit`, and `vedit-mcp`).
5. **Isolate active projects outside the engine repository**: Initialize every editing project under `VEDIT_PROJECTS_ROOT/<brand_id>/<project_id>/` using `vedit project init`. Store strictly project-relative paths in `project.json` and `plan/edit_plan.json`, and validate hygiene with `vedit project validate`. For cartographic A-roll bakes, follow [`tools/geo-assets/README.md`](../../../tools/geo-assets/README.md) (`bake_vertical_basemap.mjs` + `fast_capture.mjs` JPEG/pipe knobs). Production cloud spine: verified `EditPlan` -> `vedit compile --lint` -> `vedit cloud render` -> `vedit audit` ([`docs/CLOUD_WORKFLOW.md`](../../../docs/CLOUD_WORKFLOW.md)).
6. **Verify before cloud dispatch**: Ensure `EditPlan` passes structural verification (`vedit director verify`), `vedit compile --lint` reports zero errors, and `vedit project validate` confirms zero leaked local absolute paths. Export `.otio` via `vedit export-otio` when external NLE review is requested.
7. **Audit final output**: Run `vedit audit` to confirm target resolution, constant frame rate, explicit `bt709` color metadata via `ffprobe`, `-14.0 ± 0.5 LUFS` / `<= -1.0 dBTP` via `ebur128`, absence of unintended black/frozen segments (`blackdetect`/`freezedetect`), and optional VMAF (`--reference`).
