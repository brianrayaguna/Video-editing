# Brand Director Playbook

Operate as an **Executive Creative Director and Pipeline Operator** combining deterministic media telemetry with calibrated model decisions.

## Workflow
0. **Auto-initialize the external project**: Follow the Autonomous Production Protocol in [`AGENTS.md`](../../../AGENTS.md): derive a topic-based `project_id`, run `vedit project init` under `VEDIT_PROJECTS_ROOT`, stage inputs, write `brief.md`, and run every downstream stage on the user's behalf. Ask only for missing creative inputs or creative sign-off.
1. **Measure before directing**: Run `vedit probe analyze` to obtain verified shot boundaries, CIELAB palettes, band luminance, loudness, and silence intervals. When onboarding or calibrating a brand profile from reference videos, follow [`.agents/skills/brand-profiling/SKILL.md`](../brand-profiling/SKILL.md) (`vedit breakdown analyze` + layered `VIDEO.md` inspection + multimodal visual review → `vedit brand analyze --breakdown-file`). Use `DecisionPort` for shot classification, hook scoring, key-phrase `spans`, and target-canvas `box`/`boxes` spatial grounding.
2. **Direct the story before drafting the plan**: Build `plan/storyboard.json` ([`contracts/storyboard.schema.json`](../../../contracts/storyboard.schema.json)) before any `EditPlan` or map scene:
   - Start from `vedit storyboard auto <transcript.json> -o plan/storyboard.json --project-id <id> --brand <brand_id> [--pacing dense] [--director-file director.json]`. Without director input this is a complete, contract-valid plan from the brand's `directing_idioms.json`; with director input, director beats, locks, emphasis words and banned devices win.
   - Refine it with the brand directing method (Geoverum: [`DIRECTING.md`](../../../profiles/brands/geoverum/DIRECTING.md)): story brief, shape, hook mechanism, signature image, colour cast, and a concrete visual answer for every clause the automatic pass left on the fallback device. Fill `recent_episodes` for the variation idiom.
   - Run `vedit storyboard check plan/storyboard.json` until it passes (no errors, score `>= 70`; aim for `>= 90`). For route-driven films run `vedit storyboard journey` and build the scene from its head, camera, width and callout keys instead of hand-timing them.
   - Present the storyboard for creative sign-off when the brief asks for review.
3. **Enforce engine `DESIGN.md` and brand craft**: Read [`DESIGN.md`](../../../DESIGN.md) plus the active brand craft file under `profiles/brands/<brand_id>/` (Geoverum: [`CRAFT.md`](../../../profiles/brands/geoverum/CRAFT.md)). Apply any installed motion-craft and HyperFrames authoring skills. Keep most of the canvas calm, isolate one clear visual signal per beat, and never use generic SaaS status pills or glowing dots.
4. **Apply brand layers in order**: (1) runtime `brand_style_policy.json` soft priors + hard guardrails, (2) `templates/catalog.json` when selecting locked overlay comps, (3) `DIRECTING.md` story method and `editorial_playbook.json` grammar/exemplars as advisory directing notes only, (4) `CRAFT.md`, (5) engine `DESIGN.md`. Playbook heuristics are never executed by planner or verifier.
5. **Use cloud-first execution (thin local control plane)**: Never run heavy local speech-recognition or neural models on the directing host. Use cloud `TranscriptionPort` (`xai` / `veed`), cloud neural speech denoising and reframing (`vedit clean-audio --provider modal_cloud`, `vedit reframe --provider modal_cloud` backed by Modal CPU DeepFilterNet + FFmpeg), cloud background matting (`veed`), and `vedit cloud render` against the deployed Modal app `vedit-distributed-renderer` (which routes plain text/captions onto native FFmpeg `libass` and fans out only sparse animated HyperFrames windows). Reserve local execution for lightweight deterministic work (`vedit project`, `vedit director`, `vedit compile --lint`, `vedit export-otio`, `vedit audit`, `vedit-mcp`, and the local preprocessing commands `vedit trim`, `vedit remove-silence`, and `vedit restore-footage`).
6. **Isolate active projects outside the engine repository**: Initialize every editing project under `VEDIT_PROJECTS_ROOT/<brand_id>/<project_id>/` using `vedit project init`. Store strictly project-relative paths in `project.json` and `plan/edit_plan.json`, and validate hygiene with `vedit project validate`. For cartographic A-roll bakes, follow [`tools/geo-assets/README.md`](../../../tools/geo-assets/README.md) (`bake_vertical_basemap.mjs` + `fast_capture.mjs` JPEG/pipe knobs). Production cloud spine: verified `EditPlan` -> `vedit compile --lint` -> `vedit cloud render` -> `vedit audit` ([`docs/CLOUD_WORKFLOW.md`](../../../docs/CLOUD_WORKFLOW.md)).
7. **Verify before cloud dispatch**: Ensure `EditPlan` passes structural verification (`vedit director verify`), `vedit compile --lint` reports zero errors, and `vedit project validate` confirms zero leaked local absolute paths. Export `.otio` via `vedit export-otio` when external NLE review is requested.
8. **Critique before the final render**: On a low-resolution preview, run `vedit critique packet` (storyboard idioms, camera shake budget, grid-anchored contact sheets at each beat's sync word), score every rubric criterion from the sheets citing frame labels and grid cells, record fixes per beat, and run `vedit critique gate`. Apply fixes and repeat until the gate passes (two or three rounds at most).
9. **Audit final output**: Run `vedit audit` to confirm target resolution, constant frame rate, explicit `bt709` color metadata via `ffprobe`, `-14.0 ± 0.5 LUFS` / `<= -1.0 dBTP` via `ebur128`, absence of unintended black/frozen segments (`blackdetect`/`freezedetect`), and optional VMAF (`--reference`).

## Zero-Directing Cartographic Production Standard (Audio-Only Input)

When a user supplies only raw narration audio (with optional speed-up, e.g., `1.3x`) and asks for a `9:16` Geoverum cartographic documentary without manual beat directing, enforce these mandatory quality gates:

1. **Audio & Verbatim Self-Transcription**:
   - If a playback speedup is requested, render the sped-up master audio first (`ffmpeg -af "atempo=1.3"`).
   - If configured cloud transcription providers are unavailable, extract a `16 kHz` mono WAV and inspect it directly via `read_file` to author a verbatim `analysis/transcripts/transcript.json` with accurate segment timestamps. Never install local ASR/STT packages.
2. **Locked Bottom-Band Boxless Captions (`vedit geo build-captions`)**:
   - Always generate `build/subtitles/captions.ass` via `vedit geo build-captions <transcript.json> -o build/subtitles/captions.ass [--speed 1.3]`.
   - This locks `Rubik` Bold `56 px`, `Alignment=2` (bottom-center, `MarginV=348`, `y ≈ 80%`), `Outline=1.6`, `Shadow=3.2`, `BorderStyle=1` (100% boxless), `2–4` words per line. Each group fades in over `130 ms` (`4` frames) and cuts out hard into the next (`--fade-in-ms`, `--fade-out-ms`). Never place small captions at the top of the frame (`Alignment=8`) and never draw captions with ad-hoc `drawtext`.
3. **Sharp Aerial Ortho Imagery for Close-Ups (`vedit geo prepare --hq`)**:
   - Regional Sentinel-2 tiles (`z <= 12`) blur severely below `~2 km`. For every close-up landmark, monument, river crossing, or enclave (`zoom >= 13.5`), you MUST prepare high-resolution tiles using `vedit geo prepare --bbox "W,S,E,N:13,14,15,16" --hq -o media/maps/vectors.json` and keep `tile_source: "hybrid"` (default) or `"realistic"`.
   - `--hq` uses open imagery only: public-domain national orthoimagery (`~1 m`, up to `z16`) where it covers the area, otherwise Sentinel-2 2016 at its `~10 m` native limit (`z14`). Outside orthoimagery coverage, cap close-up zoom near `14.5` (`validate-scene` warns beyond it) or supply a project-scoped aerial plate.
4. **3D Cinema Camera Rig & Calibrated Primitives Only**:
   - Camera keyframes are rest-to-rest: the camera reaches every key at zero velocity along a C² profile chosen by the key's `curve` (`glide`, `snap_dive` for dives, `whip_snap`, `hyperbolic_fly` for cross-region hops, `orbit_cruise`); mark a key `"through": true` to pass it without stopping. Keep map frames crisp: leave `camera_smooth_s`, `auto_shutter`, and `optical_shutter_blur` off (the defaults) and reserve blur for cuts: `cut_blur_in_s` / `cut_blur_out_s` on map acts (radial zoom blur peaking on the cut frame), and the master `transition_in` values `whip_zoom_blur` (zoom-in cross) and `disc_sweep` (feathered black disc crossing the frame, for a basemap register swap at equal framing). Add `pitch` (`10–38°`), dynamic `bearing`, subtle `roll` (`±1–3°`), and optional `micro_drift`.
   - Reveal territories with `border_trace_s` (perimeter draw-on, two heads by default) followed by a colour fill or `flag_fill`; draw routes on with `draw_duration_s` and set `width_ref_zoom` so line weight follows the map scale. Bake with `vedit geo bake-scene --fill-tiles` so no frame is captured on upscaled tiles.
   - Use 3-Tier Spatial Tracking (`space: "map_plane"`, `space: "world_billboard"`, `space: "screen"`) and only calibrated boxless primitives (`polygon`, `route`, `glow_label`, `pin_label`, `curved_pointer_label`, `dashed_distance`, `curved_arc_arrow`, `void_wipe`, `counter_odometer`, `ghost_overlay`, `flag_pin`, `human_silhouette_row`, `landmark_silhouette`, `cloud_system`, `wind_streamlines`, `prohibition_pins`).
   - **Hard prohibitions (automatically rejected by `vedit geo validate-scene` and `bake-scene`)**: engraved plaques or HUD boxes (`coord_plaque`, `callout_badge`), blank black screens with horizontal bar charts (`scale_comparison`), legacy pin/star/satellite chrome (`survey_pin`, `orbital_sightlines`, `culmination_sun`), micro-typography (`font_px < 36` on `1080x1920`), ALL-CAPS label soup, or more than `3–4` concurrent text overlays.
5. **Mandatory BGM + Kinetic SFX Mastering (`vedit geo mix-audio`)**:
   - Never mux raw dry voiceover alone. Run `vedit geo mix-audio --scene-file plan/map_scene.json --voice media/audio/vo.wav -o media/audio/program_mix.wav [--bgm custom.mp3]` to combine voiceover, sidechain-ducked documentary BGM (`-16 dB` + `2.2 kHz` vocal carve), and `0 ms`-aligned kinetic SFX from `assets/audio/sfx/` (`15–28 hits/min`), mastered to `-14.0 LUFS / -1.5 dBTP`.
6. **Preflight Gate & Mandatory Visual Contact-Sheet Review**:
   - Run `vedit geo validate-scene --scene-file plan/map_scene.json` (also enforced automatically by `vedit geo bake-scene`).
   - After mastering `output/master.mp4` with `media/audio/program_mix.wav` and `build/subtitles/captions.ass`, extract a 12-frame contact sheet across the full runtime and inspect it via `read_file` before delivering to the user. Fix any blurry tiles, inverted/overlapping/clipped labels, or misaligned captions immediately.
