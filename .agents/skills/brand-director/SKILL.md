# Brand Director Playbook

Operate as an **Executive Creative Director and Pipeline Operator** combining deterministic media telemetry with calibrated model decisions.

## Workflow
0. **Auto-initialize the external project**: Follow the Autonomous Production Protocol in [`AGENTS.md`](../../../AGENTS.md): derive a topic-based `project_id`, run `vedit project init` under `VEDIT_PROJECTS_ROOT`, stage inputs, write `brief.md`, and run every downstream stage on the user's behalf. Ask only for missing creative inputs or creative sign-off.
1. **Measure before directing**: Run `vedit probe analyze` to obtain verified shot boundaries, CIELAB palettes, band luminance, loudness, and silence intervals. When onboarding or calibrating a brand profile from reference videos, follow [`.agents/skills/brand-profiling/SKILL.md`](../brand-profiling/SKILL.md) (`vedit breakdown analyze` + layered `VIDEO.md` inspection + multimodal visual review → `vedit brand analyze --breakdown-file`). Use `DecisionPort` for shot classification, hook scoring, key-phrase `spans`, and target-canvas `box`/`boxes` spatial grounding.
2. **Direct the story before drafting the plan**: When the brand ships a directing method (Geoverum: [`DIRECTING.md`](../../../profiles/brands/geoverum/DIRECTING.md)), write the project's `storyboard.md` first: story brief from the narration, detected story shape, hook mechanism, signature image, colour cast, and a clause-by-clause table of story need → visual answer synced to word timestamps. Derive structure from the story, never from a fixed beat timetable. Before drafting the `EditPlan`, run the variation audit against the brand's recent episodes so consecutive films never share both hook mechanism and ending type and never reuse a signature image. Present the storyboard for creative sign-off when the brief asks for review.
3. **Enforce engine `DESIGN.md` and brand craft**: Read [`DESIGN.md`](../../../DESIGN.md) plus the active brand craft file under `profiles/brands/<brand_id>/` (Geoverum: [`CRAFT.md`](../../../profiles/brands/geoverum/CRAFT.md)). Apply any installed motion-craft and HyperFrames authoring skills. Keep most of the canvas calm, isolate one clear visual signal per beat, and never use generic SaaS status pills or glowing dots.
4. **Apply brand layers in order**: (1) runtime `brand_style_policy.json` soft priors + hard guardrails, (2) `templates/catalog.json` when selecting locked overlay comps, (3) `DIRECTING.md` story method and `editorial_playbook.json` grammar/exemplars as advisory directing notes only, (4) `CRAFT.md`, (5) engine `DESIGN.md`. Playbook heuristics are never executed by planner or verifier.
5. **Use cloud-first execution (thin local control plane)**: Never run heavy local speech-recognition or neural models on the directing host. Use cloud `TranscriptionPort` (`xai` / `veed`), cloud neural speech denoising and reframing (`vedit clean-audio --provider modal_cloud`, `vedit reframe --provider modal_cloud` backed by Modal CPU DeepFilterNet + FFmpeg), cloud background matting (`veed`), and `vedit cloud render` against the deployed Modal app `vedit-distributed-renderer` (which routes plain text/captions onto native FFmpeg `libass` and fans out only sparse animated HyperFrames windows). Reserve local execution for lightweight deterministic work (`vedit project`, `vedit director`, `vedit compile --lint`, `vedit export-otio`, `vedit audit`, `vedit-mcp`, and the local preprocessing commands `vedit trim`, `vedit remove-silence`, and `vedit restore-footage`).
6. **Isolate active projects outside the engine repository**: Initialize every editing project under `VEDIT_PROJECTS_ROOT/<brand_id>/<project_id>/` using `vedit project init`. Store strictly project-relative paths in `project.json` and `plan/edit_plan.json`, and validate hygiene with `vedit project validate`. For cartographic A-roll bakes, follow [`tools/geo-assets/README.md`](../../../tools/geo-assets/README.md) (`bake_vertical_basemap.mjs` + `fast_capture.mjs` JPEG/pipe knobs). Production cloud spine: verified `EditPlan` -> `vedit compile --lint` -> `vedit cloud render` -> `vedit audit` ([`docs/CLOUD_WORKFLOW.md`](../../../docs/CLOUD_WORKFLOW.md)).
7. **Verify before cloud dispatch**: Ensure `EditPlan` passes structural verification (`vedit director verify`), `vedit compile --lint` reports zero errors, and `vedit project validate` confirms zero leaked local absolute paths. Export `.otio` via `vedit export-otio` when external NLE review is requested.
8. **Audit final output**: Run `vedit audit` to confirm target resolution, constant frame rate, explicit `bt709` color metadata via `ffprobe`, `-14.0 ± 0.5 LUFS` / `<= -1.0 dBTP` via `ebur128`, absence of unintended black/frozen segments (`blackdetect`/`freezedetect`), and optional VMAF (`--reference`).
